# MyProduct

MyProduct is a small example product used to demonstrate multilingual product pages in EasyDocs.

## Overview

This page is the default-language entry point for the product. Product content can include Markdown pages, images, and other static files alongside the language directories.

## Get started

Add your product introduction, feature guides, screenshots, and release notes under the `en-us` and `zh-cn` directories. Use `.order` files to keep the navigation order stable.

Read the [privacy policy](../privacy-policy.html) before using the sample product.
