# 产品展示及站点完善实施方案

## 摘要

新增独立的产品内容生成链路，保留 Docs 的版本逻辑；后端适当抽取目录、Markdown、TOC、资源复制和 URL 能力，前端使用独立的 `products.js`，不复用或修改 `docs.js` 的产品逻辑。

## 关键改动

- 在 `WebInfo` 增加 `ProductInfos`，新增 `ProductInfo`：

  ```text
  Name
  Logo
  Description
  Languages
  DefaultLanguage
  ```

  `DefaultLanguage` 必须属于 `Languages`，并且对应目录存在。

- 新增 `ProductBuilder`，支持：

  ```text
  Content/products/<name>/<language>/...
  Output/products/<name>.html
  Output/products/<name>/<language>/...
  Output/data/products/<name>/<language>.json
  Output/data/products/<name>/<language>-search.json
  ```

- 产品页面支持 Docs 同等能力：目录树、`.order`、Markdown、TOC、语言切换、搜索、Git 编辑链接、canonical 和 sitemap。

- 产品入口页使用 `DefaultLanguage` 下的第一篇 Markdown；顶部导航和首页卡片统一链接到 `products/<name>.html`。

- 产品目录中的所有非 Markdown 文件（排除 `.order`）按相对路径原样复制，不改写 HTML 内部链接。例如：

  ```text
  Content/products/MyProduct/privacy-policy.html
  -> Output/products/MyProduct/privacy-policy.html
  ```

- 修复公共目录树的 `.order` 混排问题，并让 Docs/Products 的生成链接统一使用 `BaseHref`。

- 首页拆为两个区块：`Docs` 与 `Products`。产品卡片显示名称、Logo、描述；Logo 缺失时不生成破损图片。

- About 文件使用大小写不敏感查找，`about.md` 和 `About.md` 均生成 `about.html`；两者同时存在时报告错误。顶部导航始终使用 `about.html`。

- 新增 `product.html.tpl`、`productSearch.html.tpl` 和 `WebApp/js/products.js`。Docs 页面继续使用 `docs.js`，两套前端逻辑彼此独立。新增 JS 后同步更新 `pack.ps1` 和 `web.zip`。

## 测试与验收

- 新增 `tests/Share.Tests` .NET MSTest 项目，引用 `src/Share/Share.csproj`，使用临时配置和输出目录测试：

  - ProductInfos JSON 配置；
  - 默认语言和语言切换；
  - 产品入口、详情页、搜索页和 JSON；
  - `.order`、目录树、图片及原始 HTML；
  - 搜索、编辑链接、canonical、sitemap；
  - Docs 回归；
  - `about.md` / `About.md`；
  - 根路径和子路径 `BaseHref`。

- 新增 `tests/E2E` Playwright 项目及原始 fixture：

  ```text
  tests/E2E/fixtures/Content/products/MyProduct/
  ├── en-us/
  ├── zh-cn/
  ├── logo.png
  └── privacy-policy.html
  ```

  E2E 测试先用 Release CLI 生成临时静态站点，再启动静态服务器验证首页、导航、产品详情、语言切换、搜索、About 和原始 HTML 链接。

- 运行：

  ```powershell
  dotnet build .\src\BuildSite\BuildSite.csproj -c Release
  dotnet test .\tests\Share.Tests\Share.Tests.csproj -c Release
  dotnet test .\src\ColorCode.Core.Tests\ColorCode.Core.Tests.csproj -c Release
  cd tests/E2E
  npm ci
  npx playwright install
  npm test
  ```

- 更新 `README.md`、`README_cn.md`、根目录 `webinfo.json`，并添加 `Content/products/MyProduct` 示例内容及测试资源。

## 默认决策

- 配置集合名称固定为 `ProductInfos`。
- 产品静态资源保持原样，不自动改写绝对路径、相对路径或 HTML 内容。
- 产品搜索页路径为 `products/<name>/<language>/search.html`。
- sitemap 收录产品入口页和 Markdown 详情页，不收录搜索页及原始静态 HTML。
- 现有用户对 `README_cn.md` 和 `docs/` 的改动保留不动。
